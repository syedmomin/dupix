A **Duplicate File Cleaner** is a solid Play Store idea because many Android users run into storage issues. The challenge is that there are already many apps in this category, so you'll need to offer a cleaner, faster, or more trustworthy experience.

## App Name 
* **Dupix**

## Core Features (v1)

### Duplicate Photos

* Find exact duplicate photos
* Group duplicates together
* Keep the best quality automatically
* One-tap delete

### Duplicate Videos

* Find duplicate videos
* Sort by size
* Preview before deleting

### Duplicate Audio

* Songs
* Voice recordings
* Music files

### Duplicate Documents

* PDF
* DOCX
* PPTX
* TXT

### Duplicate APKs

* Old APK files
* Multiple versions

### Large Files

* Files over a user-defined size (e.g. 100 MB)
* Sort by size
* One-tap cleanup

## Smart Features (v2)

* Similar photo detection (not just exact duplicates)
* Blurry photo detection
* Screenshot cleanup
* WhatsApp media cleanup
* Telegram media cleanup
* Download folder cleanup
* Empty folder cleanup
* Temporary cache cleanup

## Premium Features

### One important note

A focused promise such as **"Find and remove duplicate photos, videos, documents, and large files to recover storage space"** is more accurate and more likely to comply with Play Store policies.
